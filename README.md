# 🎯 하루 계획 코치 (Planner Agent)

사용자의 할 일과 시간 제약을 바탕으로 현실적이고 효과적인 하루 일정을 설계하는 AI 기반 계획 코치입니다.

## ✨ 주요 기능

- **🎯 현실적인 계획 설계**: 할 일과 사용 가능한 시간을 고려한 맞춤형 일정
- **⏰ 우선순위 자동 정리**: 중요도와 긴급성을 고려한 작업 순서 제안
- **💡 스마트 시간 관리**: 집중 시간, 휴식 시간, 식사 시간을 고려한 균형잡힌 계획
- **📅 타임라인 형식**: 명확하고 실용적인 시간별 일정표 제공
- **🤖 AI 기반 조언**: GPT를 활용한 개인화된 계획 코칭

## 🚀 설치 및 실행

### 1. 의존성 설치
```bash
npm install
```

### 2. 환경 변수 설정
프로젝트 루트에 `.env` 파일을 생성하고 OpenAI API 키를 설정하세요:
```
OPENAI_API_KEY=your_openai_api_key_here
PORT=3000
```

### 3. 서버 실행
```bash
# 개발 모드 (nodemon 사용)
npm run dev

# 프로덕션 모드
npm start
```

### 4. 브라우저에서 접속
```
http://localhost:3000
```

## 📋 사용 방법

1. **할 일 입력**: 오늘 해야 할 일들을 텍스트로 입력
2. **시간 설정**: 사용 가능한 시간을 선택 (2~10시간)
3. **계획 생성**: "하루 계획 만들기" 버튼 클릭
4. **결과 확인**: AI가 생성한 현실적인 일정표 확인

## 🏗️ 파일 구조

```
├── index.html          # 메인 페이지 (하루 계획 코치)
├── planner.js          # Planner Agent JavaScript
├── style.css           # 스타일시트
├── server.js           # Express 백엔드 서버
├── package.json        # 프로젝트 설정
└── .env               # 환경 변수 (API 키 등)
```

## 🔒 보안

- OpenAI API 키는 서버의 `.env` 파일에서 안전하게 관리
- 프론트엔드에서는 API 키가 노출되지 않음
- 백엔드 프록시를 통한 안전한 API 호출

## 🛠️ 기술 스택

- **프론트엔드**: HTML, CSS, JavaScript (ES6+)
- **백엔드**: Node.js, Express
- **AI**: OpenAI GPT-3.5-turbo
- **스타일**: Pretendard 폰트, Apple 스타일 디자인

## 🎯 Planner Agent 특징

- **친근한 말투**: 친구처럼 다정하되 현실적인 조언
- **맥락 이해**: "시간 없어ㅠ", "오늘 뭐하지?" 같은 질문도 이해
- **우선순위 제안**: 시간이 부족할 때 중요한 일부터 제안
- **현실적 조언**: 실행 가능한 구체적인 팁 제공

## 📝 예시 사용법

**입력 예시:**
```
- 10시 회의
- 오후 2시까지 보고서 작성
- 저녁 7시 운동
- 밤 10시까지 독서
```

**출력 예시:**
```

09:30~10:00 회의 준비

14:00~15:00 휴식 및 정리
15:00~16:00 개인 업무
16:00~17:00 휴식
17:00~18:00 운동 준비

💡 팁: 보고서는 오전에 집중해서 완료하고, 오후에는 여유를 두는 게 좋겠어요!
```
